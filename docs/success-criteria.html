How we know it is good

Each criterion names a source. The source is why the line exists — not a claim that Kadmon already meets it.

Sign-in: subscription-auth.md (separate doc)

Product

Kadmon is a teammate coding agent. You give it a Task or a Project. A Task comes back as a pull request that already passed the repo’s tests and an independent review. A Project stops for a design YES/NO, then those PRs. It asks only when direction is unclear. It writes skills that fire the next time. Cheap models do the work. Evals carry correctness.

Two layers

Internal gates can be arbitrary. An agent can pass them and still lose on a public protocol, and still ship bugs after merge. Passing only one layer is not success.

A — Workplace

Does it finish real work with almost no babysitting? Failure if used alone: easy gates on a repo we wrote.

B — Public comparison

Is the same system competitive on a published protocol? Failure if used alone: can take a test, cannot ship a PR.

A third check sits after merge: defects that come back. That is DORA change-fail rate, applied to agent-merged work.16

No 1–5 scores. No live conversation-watcher. Binary pass/fail and code assertions first.1,2 An LLM judge only when a mechanical check cannot exist, and then still binary.

Comparison card

A card without a date, harness, model, and same-model baseline row is void. Comparing Kadmon+Grok to a SOTA row on another model confounds scaffold and model. Terminal-Bench finds model choice usually moves the score more than the scaffold.10 The control row is what makes the number about Kadmon.

Tied means intervals overlap. We do not say “better” inside overlapping error. Wilson, not Wald: Wald collapses at 0/n and under-covers at small n. Brown, Cai, and DasGupta recommend Wilson for binomial proportions.14 At n≈10, 8/10 has a Wilson 95% interval of roughly 49–96%.

Layer A — Workplace

First dogfood: convo-agent. Until a second repo not authored here has run Tasks, these numbers are in-distribution only. Do not pool. SWE-bench Pro’s private split is harder than public for this reason.18

Class: Task vs Project

Default is Task. It becomes a Project if any tripwire is YES. The agent does not self-certify class.

  • User labeled it project / RFC / design.
  • Mechanical (a script on the diff): new public-API path, provider, datastore migration, or production secret name.
  • Cannot ship as one PR.
  • AGENTS.md or a skill marks the area as design-first.

On convo-agent, A1 / C0 / Phase 6 are Tasks. Phase 7 (durable DB) and V2 (converser/grader split) are Projects.

P7 No re-ask After handoff, no directional question already answered in the brief Re-asks a resolved design question Decision retention is “it did not forget,” measured.6
P8 Reset At the utilization threshold: write a brief, then reset. Not only delete middle turns Silent truncation Bigger windows delay degradation; they do not remove it.6 METR: the bottleneck on long software work is finishing the horizon.8

P6–P8 are the Project-specific addition. Tasks are usually one context. Projects are not. A Project that looks fine in the first hour and forgets the design in the third has failed these lines, even if T2 is green on the last PR.

Growth

IDYESWhy
G1 Wrote New or updated SKILL.md (not a diary) Skills package how. Session notes are where we left off. Different objects.17
G2 Fired Log shows load, and the declared precondition matched A file nobody loads is not learning.
G3 Delta Report tokens / rounds / questions. No “helped” verdict on n=1. Pre-register one metric only if we can measure variance One of three metrics often moves down by chance. Causal claims need a pre-registered outcome and a variance baseline.

Lagging practice — L1

Of the last N merged Tasks, how many needed a corrective PR within 14 days. Wilson 95% CI. Lives in the weekly headline.

DORA change fail rate: the share of changes that need a hotfix, rollback, or fix-forward after they ship.16 Pre-merge gates cannot see this. T5 (silence) is honest only because L1 exists.

In-repo warning: convo-agent’s coherence tag ran on every turn and, in evals/coherence/, tagged a gaming turn on_track every time. A watcher LLM is not L1.

Layer B — Public comparison

Headline: Senior SWE-Bench via Harbor, always with a same-model baseline scaffold row. Underspecified, PR-shaped, tasteful-solve. Published SOTA was about 29% in July 2026 — on a different model, which is why that number is never the only row.9

Secondary only: Terminal-Bench 2.x, same three-row shape.10 Never the headline.

Not on the card: SWE-bench Verified (saturated, no longer a frontier headline).5,18 Aider Polyglot as capability. METR unless we actually freeze and run a suite.8 Kadmon’s current nonempty-patch harness.

  • Same harness as the cited row (Harbor).10
  • Three rows or the card is void.
  • Same split the leaderboard uses. If the public split is dirty, use the authors’ recommended split.18
  • No gold-PR lookup. Newer models reward-hack.9
  • Cost and wall-clock on all three rows.
  • We do not tune prompts on the split we report.

What we will not score as a goal

  • SWE-bench Verified headline %
  • Aider Polyglot as capability
  • Live LLM-as-watcher
  • 1–5 taste scores1,2
  • Library file count
  • A dollar cap we set ourselves
  • “Helped” on a single pair of Tasks
